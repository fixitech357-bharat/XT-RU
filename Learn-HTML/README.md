An interactive, production-ready educational web platform designed to take learners from **absolute beginners to certified HTML5 & Web Architecture masters**.

---

## 🌟 Key Highlights & Modules

### 1. 📚 5 Comprehensive Tracks (25 In-depth Topics)
- **Beginner (🌱)**: Intro to HTML, Document Anatomy, Headings, Text Styling, Ordered & Unordered Lists.
- **Intermediate (🔷)**: Anchors & Links, Images & Figures, Complex Data Tables, Forms & Inputs, Block vs Inline.
- **Advanced (🚀)**: HTML5 Semantic Architecture, Audio & Video, Iframes & Sandboxing, Meta Tags & OpenGraph, Character Entities.
- **Expert (🧠)**: HTML5 Canvas 2D Graphics, Custom `data-*` Attributes, Web Storage (localStorage), WAI-ARIA Accessibility, Native Form Constraints.
- **Master (👑)**: Modern Flexbox & CSS Grid Integration, Mobile Responsive Design, Performance Engineering, Capstone Project Architecture.

### 2. 🧪 Interactive Code Lab (Hands-on Challenges)
- Solve real coding tasks directly in an interactive code editor.
- Instant automated test suite checking your DOM tree structure (e.g. `article`, `figure`, `caption`, `aria-label`, `dialog`).
- Immediate visual test result checkmarks.

### 3. 📖 60+ HTML5 Element Cheatsheet
- Searchable tag dictionary with real-time keyword filtering.
- Grouped by: Structure, Semantic, Text, Forms, Media, Tables, and Modern Interactive tags (`<dialog>`, `<details>`, `<summary>`).
- **Try in Playground** button loads any tag directly into the live sandbox with 1 click.

### 4. ⚡ Live Multi-Tab Code Playground
- Live HTML, CSS, and JavaScript editor with instant isolated `<iframe>` preview.
- Preset templates: Responsive Glass Card, Accessible Contact Form, Canvas Animation, and Hello World.
- Real-time JavaScript console output interception.
- One-click `.html` project file exporter.
- Hotkey support: `Ctrl + Enter` to run code immediately.

### 5. 📜 Final Exam & Canvas Certificate Generator
- 25-question comprehensive timed examination (20-minute timer).
- Dynamic HTML5 Canvas rendering of an official **Certificate of Excellence** (1200×800px).
- Includes Candidate Name, Score Percentage, Date, and Unique Cryptographic Credential ID.
- One-click **Download High-Res PNG** and **Share on LinkedIn** integration!

### 6. 🏆 Gamified Badges & Local Leaderboard
- Unlockable achievements (`First Step`, `Beginner Graduate`, `Playground Hacker`, `Lab Champion`, `HTML5 Certified`, `Grand Master`).
- Multi-metric local leaderboard ranking learners by lessons completed, lab challenges solved, and exam scores.
- Customizable learner profile with emoji avatars.

### 7. 🔊 Procedural Web Audio Synthesis
- Built-in audio cues using native `AudioContext` (success chimes, failure buzzes, victory fanfares, click feedback).
- Sound mute/unmute persistent toggle.

## 🚀 How to Deploy to Vercel (Step-by-Step)

### Option A: Using Vercel CLI
```bash
# 1. Install Vercel CLI (if not installed)
npm i -g vercel

# 2. Deploy directly from your project directory
vercel
```

### Option B: Deploy via GitHub
1. Create a new repository on [GitHub](https://github.com/new) named `html-master`.
2. Push your project files:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of HTML Master platform"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/html-master.git
   git push -u origin main
   ```
3. Go to [Vercel](https://vercel.com/new), select your GitHub repository, and click **Deploy**. Vercel will immediately deploy the static site!

## 💼 How to Share Your Certificate on LinkedIn
1. Open the platform and navigate to **Final Exam**.
2. Complete the 25 questions with a score of 70% or higher.
3. Click **Claim & Download Your Certificate**.
4. Click **Share on LinkedIn** to automatically generate a post with your score, tags, and credential, or click **Download Certificate (High-Res PNG)** to attach the image to your post!

## 💻 Local Development

Run locally using any static file server:
```bash
# With Node.js / npx
npx serve . -p 3000

# Or with Python
python -m http.server 3000
```
Or simply double-click `index.html` to open it in Google Chrome, Microsoft Edge, Firefox, or Safari!
